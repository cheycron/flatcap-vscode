# Change Log

All notable changes to the "flatcap-theme" extension will be documented in this file.

## [2.0.0] - 2026-11-05

- Rebuilt on the Flatcap 2.0 core (`src/theme.json`) with role-based mapping.
- New themes: **Flatcap Slate** (dark) and **Flatcap Daylight** (light).
- The v1 ID `Flatcap` stays as an alias of Slate, labelled "Flatcap (v1 name, now Slate)".
- Added `scripts/build.py` (`--check`, `--sync`, `--contrast`); generated files must not be edited by hand.
- Removed the v1 palette, theme file and v1 images.

## [1.1.0] - 2026-01-19

- Updated the theme with a new design system, refined icons and typography.
- Renamed the display name to "Flatcap Theme" and updated the description, repository URL and keywords.
- Rewrote the README and added a screenshot.
- Added a direct Marketplace link to the README.

## [1.0.2] - 2025-07-15

- Added Buy Me a Coffee link for support.

## [1.0.1] - 2025-07-10

- Added language-specific demo images for PHP, Javascript, Rust, and Go.
- Replaced SVG icons with PNG for better compatibility.

## [1.0.0] - 2025-07-07

- Initial release
- Standardized theme name and metadata.
- Corrected VS Code engine version.
- Removed erroneous references to a light theme.
